## Facts and references

`assets/gemini-models.json` and `references/gemini-models.md` record model names, status, dates, and request shapes
from Google's public documentation, and report what community threads said. No documentation text or third-party code
is reproduced beyond short identifiers and quoted phrases.

This skill was informed by studying one app's behaviour. That app's licence forbids copying, so none of its code or
prompts is included. `references/gemini-models.md` records which public model names it tries and in what order, as a
fact about its behaviour.
